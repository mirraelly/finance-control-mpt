# Finance Control Frontend

Projeto React + Vite com a tela de cadastro convertida de HTML/CSS/JavaScript para React.

## Executar

```bash
npm install
npm run dev
```

A aplicação será disponibilizada pelo Vite em `http://localhost:5173`.

## Tela de cadastro

O cadastro está em `src/components/layout/Auth/Cadastro.jsx`, com estilos em `Cadastro.css`.
